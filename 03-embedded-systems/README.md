# 03: Embedded systems

The idea for thsis subrepo is to help us when moving from Arduino-style sketches to writing real firmware.

## Topics
- Choosing a microcontroller: Arduino, RP2040 (Pico), ESP32
- Bare-metal C with the Pico SDK
- Communication: UART, I2C, SPI, plus wireless links like ESP-NOW
- Interrupts, timers, and DMA
- Debugging: serial logging, logic analyzers, reading a hard fault
- Intro to an RTOS (FreeRTOS)
