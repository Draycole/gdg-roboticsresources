# 05: ROS and manipulation

Robot software at the system level.

## Topics
- ROS 2 concepts: nodes, topics, services, actions
- URDF and robot descriptions
- Forward and inverse kinematics
- Simulating in Gazebo
- Motion planning with MoveIt 2
- Simulating a 6-axis collaborative arm

## Read this first
This stage assumes you understand sensors, firmware, and basic control from stages 2 to 4. Jumping straight into ROS without them is the most common reason people stall.
