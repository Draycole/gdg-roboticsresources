# 01: Foundations

The electronics and programming you need before touching sensors.

## Topics
- Voltage, current, resistance, and Ohm's law in practice
- Breadboards, multimeters, and reading a circuit diagram
- Reading a datasheet: absolute maximum ratings, pinouts, timing
- C/C++ for hardware: types, bitwise operations, functions, pointers
- First programs: blink, button input, serial output
