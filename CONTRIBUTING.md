# Contributing

Anyone in the track can contribute. So please, once you've found something you feel would be useful to all members of the track, feel free to take the steps listed below to have them included. Plus it's also a good way to practice your git skills.

*where PR -> Pull Request 

<br>

**Add a link:** open a PR adding one entry to the right file in `curated-links/` using the entry format in that folder's README.

**Add or fix material:** keep each topic in its own folder with a README that states what it is, what it needs, and how to run or wire it. Code should build as committed. Say which board and toolchain you tested on.

**Naming:** lowercase, hyphen-separated, no spaces or brackets (`servo-motors`, not `wk3 (servo motors)`).

**Credit:** if your material builds on someone else's work, say so and link it.

**Small PRs are welcome.** One topic per PR makes review quick.
