# Control and simulation (stage 4)

> Seed list written from general knowledge. Verify each link and fill in "Last checked" before merging.

## Start here, in this order

1. **Brian Douglas, Control Systems Lectures** (YouTube). Watch the PID and state-space playlists. Then tune the PID baseline in [self-balancing-robot](../04-control-and-simulation/self-balancing-robot) and write down what each gain did.
2. **OpenAI Spinning Up, "Key Concepts in RL"**: [spinningup.openai.com](https://spinningup.openai.com). Read the introduction, then run the PPO training in the self-balancing robot project and read your training curve with it open.
3. **MuJoCo documentation**: [mujoco.readthedocs.io](https://mujoco.readthedocs.io). Read the overview and the modeling chapters, then open the robot's model file and find each body and joint.
