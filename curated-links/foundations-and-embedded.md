# Foundations and embedded systems (stages 0 to 3)

> Seed list written from general knowledge. Verify each link and fill in "Last checked" before merging.

## Start here, in this order

1. **Arduino documentation and built-in examples**: [docs.arduino.cc](https://docs.arduino.cc). Do the Blink, Button, and AnalogRead examples first. Then do our ultrasonic and servo labs.
2. **Raspberry Pi Pico documentation**: [raspberrypi.com/documentation](https://www.raspberrypi.com/documentation). Read "Getting started with Raspberry Pi Pico", then build the blink example in C.
3. **Making Embedded Systems** (Elecia White). Read the chapters on interrupts and communication after you have written your first bare-metal program.
